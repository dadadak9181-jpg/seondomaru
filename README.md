# 선도마루 상세페이지 수정본

- `index.html`: 화이트 스프레이로 바로 이동합니다. 별도 첫 화면은 없습니다.
- 상단 탭으로 화이트 / 블랙 상세페이지 전환
- 페이지 `.page`의 최대 폭은 **860px**; 모바일 화면은 100%에 맞춰 축소
- `assets/story_01.jpg` ~ `story_05.jpg`: **사용자가 전달한 실제 일러스트 원본 5장**을 포함
- 각 스토리 이미지 위쪽의 카피는 HTML로 올려 두어 수정이 가능합니다. 이미지 자체에 글씨를 합성하지 않았습니다.
- `assets/black-real-original.png`는 전달된 실제 작업 사진입니다. 블랙의 제품 설명은 ‘체내 주입형 / 활어 체내에 주입’으로 작성했습니다.
- 두 제품 모두 다양한 활용 가능성 및 게시판 상담 안내 포함
- 제품 상세페이지에 무허가 용도나 입증되지 않은 효능을 단정하는 문구를 추가하지 않았습니다.
